# 固定ヘッダー・フッターと本文スクロールの設計

## 目的

ログイン後の全画面を、固定ヘッダー、スクロール可能な本文、固定フッターの三段構成に統一する。AIチャット画面では、過去の会話をスクロールしても入力欄を常にフッター直上に表示する。

## 対象範囲

- ログイン後の全画面の共通レイアウト
- ホーム画面のロゴ・設定ボタンを含むヘッダー
- 各詳細画面の戻るボタン・タイトル・右側操作を含むヘッダー
- 5項目の共通フッター
- AIチャットのメッセージ領域と入力欄
- 画面遷移時およびチャット更新時のスクロール位置

ログイン画面、API、保存データ、認証処理は変更しない。

## レイアウト構造

ログイン後の共通レイアウトを、動的ビューポート高に収まる縦方向の Flex コンテナにする。

1. ヘッダーは `shrink-0` の固定領域とする。
2. 本文は `flex-1 min-h-0 overflow-y-auto` の唯一の縦スクロール領域とする。
3. フッターは `shrink-0` の固定領域とする。
4. ルートと `body` のページスクロールを発生させない。

ヘッダーとフッターを `position: fixed` で本文へ重ねるのではなく、ビューポート内の通常フローに置く。これにより、本文が固定領域の背後へ隠れることを防ぐ。

スマホでは `100dvh` 相当の動的ビューポート高を利用し、ブラウザのアドレスバーやソフトウェアキーボードによる表示領域の変化へ追従する。フッターの見た目と既存の高さは維持する。

## ヘッダー

- ホーム画面では、現在本文内にあるロゴと設定ボタンを共通ヘッダー領域へ移す。
- その他のログイン後画面では、現在の戻るボタン、画面タイトル、共有などの右側操作を共通ヘッダー領域に表示する。
- ログイン画面にはヘッダーを表示しない。
- ヘッダーは本文のスクロール位置に影響されない。

## フッター

- 現在の5項目のナビゲーションと選択状態を維持する。
- フッターを本文へ重ねず、共通レイアウトの最下段に置く。
- ログイン画面にはフッターを表示しない。
- 既存のチャット起動ボタンなど、フッター基準で配置される浮動要素は、新しいフッター位置と重ならないことを確認する。

## 本文スクロール

- 共通レイアウトの本文要素だけに縦スクロールを許可する。
- 各ページにある不要な `min-h-screen` と、固定フッターを避けるためだけの下余白を取り除く。
- 横方向のはみ出し防止は維持する。
- 画面遷移時は本文要素の `scrollTop` を `0` に戻す。
- 無限スクロールを使うレシピ一覧とブックマーク一覧は、本文スクロール領域内でも最終項目の監視が動作することを確認する。

## AIチャット

- メッセージ履歴は本文とともに縦スクロールできる。
- 返信候補、画像添付、テキスト入力、送信ボタンを含む入力欄は、本文スクロール領域の下端に `sticky` で固定する。
- 入力欄はフッターの上にある本文領域内へ収まるため、フッター用の固定オフセットは持たせない。
- 新しいメッセージまたは処理中状態の更新時は、`window` ではなく本文スクロール領域の末尾へ移動する。
- ユーザーが入力欄を操作している間も、本文だけがスクロールする。

## 状態とデータの流れ

- 共通レイアウトが本文スクロール要素への参照を持つ。
- ルート変更時、共通レイアウトが本文を先頭へ戻す。
- AIチャットは末尾アンカーを `scrollIntoView` し、最も近い本文スクロール要素だけを動かす。
- APIリクエスト、チャットメッセージ、献立データの形式は変更しない。

## エラーと互換性

- JavaScript が一時的に実行されない場合でも、Flex レイアウトだけでヘッダー・本文・フッターの配置を維持する。
- スクロール参照がまだ存在しない初期描画では何もせず、次の描画で通常の位置制御を行う。
- 短い本文では不要な縦スクロールを発生させない。
- 長い本文、横幅の狭いスマホ、デスクトップの最大幅表示でレイアウトが崩れないようにする。

## テストと検証

1. 共通レイアウトを描画し、ビューポート固定、本文のみスクロール、ヘッダーとフッターが非スクロール領域であることをテストする。
2. ログイン画面ではヘッダーとフッターが表示されないことを既存挙動と照合する。
3. AIチャット入力欄に sticky 下端固定が設定されていることをテストする。
4. 画面遷移時の先頭復帰と、チャット更新時の末尾移動を、実際のスクロール対象に対してテストする。
5. 全テスト、Biome、クライアント本番ビルドを実行する。
6. ログイン可能な環境では、スマホ幅とデスクトップ幅でホーム、一覧、詳細、設定、献立作成、AIチャットを目視確認する。

## 完了条件

- ログイン後の全画面でヘッダーとフッターが動かない。
- ページ全体ではなく中央の本文だけをスクロールできる。
- AIチャット入力欄が常にフッター直上に表示される。
- 本文がヘッダー、入力欄、フッターの背後に隠れない。
- 画面遷移とチャット更新で意図したスクロール位置になる。
- 既存のナビゲーション、横幅調整、チャット返信候補に回帰がない。
